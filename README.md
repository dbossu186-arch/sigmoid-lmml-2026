# Sigmoid LMML 2026: team "Chinese spy" solutions

One folder per country task. Each folder has the solution code and a README explaining the method. Answer flags are redacted.

| Region | Tasks |
|---|---|
| Europe | Albania, Belgium, Estonia, Finland, France, Germany, Greece, Iceland, Moldova, Norway, Portugal, Romania, Spain, Switzerland, United_Kingdom |
| Asia | Bhutan, China, India, Japan, Laos, Mongolia, Vietnam |
| Africa | Egypt, Nigeria, Rwanda, Senegal, South_Africa, Tanzania |

Notes:
- **Japan:** work in progress (photo-attribution analysis), not a passed task.
- **Vietnam:** still being finished. The grader expects a plain convnext_tiny checkpoint dict.
- **Data:** each folder has the task's input files in `data/`, next to `TASK.md` (the statement and expected output) and the solution. The big image sets (China, India, Japan, Laos) and France's table aren't stored here. Their `DATA.md` gives the download link.
